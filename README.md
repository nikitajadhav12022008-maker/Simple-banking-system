#💰SIMPLE BANKING SYSTEM:
A simple banking system which defines balance and account number and prints the amount whether it is credited or debited respectively.

##🚀Features:
*Contains a class named Account
*Contains a constructor where we define self,balance and account number
*Contains debit and credit methods using functions 
*Defines a get_balance method which returns the balance
*Contains a object named acc1
